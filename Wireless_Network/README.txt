SIMPLE WIRELESS NETWORK PRACTICAL

Files:
- server.py: receives a message and sends a reply.
- client.py: sends one message and displays the reply.
- simpy_code.py: simulates three wireless nodes sending packets.

Run server/client:
1. Open a terminal and run: python server.py
2. Open another terminal and run: python client.py
3. Run again for another client after the first client finishes.

Run simulation:
1. Install SimPy: python -m pip install simpy
2. Run: python simpy_code.py

These are simplified educational examples. The socket programs demonstrate
network communication but do not implement Wi-Fi radio protocols.
